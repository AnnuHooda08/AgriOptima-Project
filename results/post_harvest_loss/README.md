# Post-harvest model evaluation

Generated by `models/04_post_harvest_loss.ipynb`. The source contains 1,865
published study values. A grouped historical test has 490 rows, including
28 overall totals. Stages of one state-crop combination never cross the split.

The remaining 1,375 rows contain an inner grouped validation split. It selects
absolute-error tree splits, minimum leaf size 1 and unrestricted depth from
16 forest configurations. The forest contains 200 trees.

| Method | Historical test MAE in percentage points |
| --- | ---: |
| Constant training median | 0.993702 |
| Training loss-type/stage median | 0.355590 |
| Validation-selected Random Forest | 0.344191 |

Overall-total-only MAE is 1.039850, which is higher than the combined score.
This is a reused historical benchmark, not fresh external or farm validation.
The forest is not guaranteed to beat baselines on other samples.

The FAO export contains 1,399 India records from 21 references. It mixes studies,
years, stages and geographical levels. The farm workbook does not contain a
compatible post-harvest loss target. These sources were reviewed, not silently
merged into training. The original government report download returned HTTP
404 during the compatible-data search. No extra training rows are claimed.

The website bundle is `backend/saved_models/post_harvest_loss.joblib`.
`/api/loss-analysis` reports the published reference and model estimate
separately. A user can choose the model for planning; an explicit user loss
percentage overrides either method. Unknown input categories return no model
estimate instead of an unlabelled extrapolation.
